# X-PORTAL nach SGMM II

Managementarchitektur nach dem St. Galler Management-Modell (Bleicher): normativ, strategisch, operativ × Aktivitäten, Strukturen, Verhalten. Dazu Bauphasen (Container nur als Übergang, danach Holzhäuser), Change Requests CR-01 bis CR-05 an das Entscheidungslog und zwölf Funktionsketten F01–F12 bis auf Werkzeug, Preis, Person und Ausfall. Stand 12.11.2026.

Online: https://claude.ai/artifact/EYuUZwYARAk6bVpmPDyq9G (privat).

| Datei | Wofür |
|---|---|
| `sgmm.md` | Für Agenten zuerst lesen. |
| `sgmm.json` | Maschinenlesbar: `matrix`, `bauphasen`, `change_requests`, `funktionsketten` (mit Preisen in UAH), `abgleich_neu` (W19, W20). |
| `sgmm.html` | Lesbare Seite. |
| `werkzeug/sgmm.py` | Generator; die Daten stehen oben im Skript. Ändern und `python3 werkzeug/sgmm.py .` aus diesem Ordner ausführen. |
